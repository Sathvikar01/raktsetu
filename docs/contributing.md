# Contributing

The contribution guide lives at the repository root: [CONTRIBUTING.md](../CONTRIBUTING.md).

It covers development setup, branch naming, conventional commits, test requirements
(invariant tests are mandatory for privacy-touching changes), code style, and the PR checklist
including the privacy review question: *"Does this change reveal more than before?"*

Related documents:

- [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) — community standards
- [SECURITY.md](../SECURITY.md) — vulnerability reporting and disclosure policy
- [CONTRACTS.md](../CONTRACTS.md) — hard rules that win over code
